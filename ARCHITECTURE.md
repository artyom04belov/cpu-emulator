# Архитектура и ассемблер

## Устройство

Единая память: 256 слов по 32 бита (1024 байта), адресация по словам, адреса 0…255. Команды и данные находятся в одной изменяемой памяти. Отдельного скрытого хранилища исполняемых инструкций нет. Изменение команды в памяти изменяет дальнейшее выполнение.

R0…R7 — восемь 32-битных регистров общего назначения. PC хранит адрес следующей команды, IR — выбранное слово команды. MAR и MDR показывают адрес и слово последней выборки команды (не все внутренние обращения к данным). PC после выборки последней ячейки может быть 256; попытка следующей выборки вызовет ошибку.

АЛУ выполняет сложение, вычитание, умножение и беззнаковое сравнение. Результат арифметики записывается по модулю 2³². C отмечает переполнение/заём последней арифметической операции; это не накопительный признак переполнения всей свёртки. Z означает нулевой результат. CMP устанавливает Z (равно), GT (больше), LT (меньше), C (меньше/заём). Арифметика обновляет Z/C и сбрасывает GT/LT. MOV и переходы не меняют флаги.

## Этапы

1. Выборка: MAR ← PC, MDR ← память[MAR], IR ← MDR, PC ← PC + 1.
2. Декодирование: выделение кода операции и двух полей операндов, проверка формата.
3. Выполнение: чтение операндов, операция, запись результата или изменение PC.

Это логические этапы учебной модели, а не электрические такты реального процессора. Интерфейс подсвечивает следующий этап и его блок на схеме. Подробности завершённого этапа выводятся в журнал. HALT завершает выполнение.

## Машинное слово

Биты 31…24: код операции (8 бит). Биты 23…12: первый операнд (12 бит). Биты 11…0: второй операнд (12 бит). У переходов используется только первый операнд, у HALT/NOP операнды не используются.

В каждом операнде старшие 2 бита задают режим, младшие 10 — значение:

| Режим | Синтаксис | Значение |
|---|---|---|
| 00 | `array` или `[array]` | Содержимое ячейки по прямому адресу 0…255 |
| 01 | `#6`, `#array` | Константа 0…1023 или адрес метки как константа |
| 10 | `R0` | Регистр R0…R7 |
| 11 | `[R0]` | Память по адресу, записанному в регистре |

Большие константы uint32 помещают в `.word`, затем читают из памяти. Например `MOV R0, big`, где `big: .word 4294967295`.

## Команды

Двухадресность означает два явных операнда у команд обработки данных: первый обычно является и источником, и местом записи результата. Переходам достаточно одного адреса, остановке — ни одного.

| Код | Команда | Действие |
|---|---|---|
| 0 | HALT | Остановка |
| 1 | MOV A, B | A ← B |
| 2 | ADD A, B | A ← A + B |
| 3 | SUB A, B | A ← A − B |
| 4 | MUL A, B | A ← A × B |
| 5 | CMP A, B | Сравнить без записи результата |
| 6 | JMP label | Безусловный переход |
| 7 | JZ label | Переход при Z=1 |
| 8 | JNZ label | Переход при Z=0 |
| 9 | JA label | Переход при GT=1 после CMP |
| 10 | JB label | Переход при LT=1 после CMP |
| 11 | NOP | Нет операции |

У переходов метка означает адрес перехода, а не содержимое памяти. В константу записывать нельзя. Разрешены операции память–память. Стек, ввод-вывод, прерывания и конвейер не реализованы.

## Парсер

Два прохода: первый определяет адреса меток и размеры строк, второй кодирует команды и данные с разрешёнными адресами. Комментарии начинаются с `;`, метки заканчиваются `:`, операнды разделены запятыми. Мнемоники и регистры не чувствительны к регистру букв; метки чувствительны. Числа поддерживают десятичную и Python-формы `0xFF`, `0b11`. `.word` размещает одно или несколько слов. Входная точка — адрес 0, поэтому сначала размещают код, затем данные после HALT.

Ассемблер сообщает номер ошибочной строки. Выход за память и неизвестные команды при исполнении вызывают ошибку. Исходные строки для подсветки сохраняются отдельно только для интерфейса; процессор их не исполняет. При самоперезаписи кода подсветка по-прежнему относится к исходному тексту.
