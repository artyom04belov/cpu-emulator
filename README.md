# CPU Emulator — Neumann Lab

Учебный эмулятор двухадресного процессора с архитектурой фон Неймана.
Python 3.10+ и Tkinter, без сторонних Python-библиотек.

## Запуск в VS Code

1. Откройте папку проекта через File → Open Folder.
2. Выберите интерпретатор Python через Python: Select Interpreter (если установлено расширение Python).
3. Откройте встроенный терминал и выполните `python3 main.py` (в Windows обычно `python main.py`).
4. Нажмите «Максимум» или «Свёртка». Программа уже собрана и готова.
5. Нажимайте «Этап»: последовательно выполняются выборка, декодирование и выполнение.
6. «Пуск» включает автоматическое выполнение; «Пауза» останавливает его. Поле мс/этап задаёт задержку. Для свёртки удобно установить 1–10 мс.
7. Измените шесть чисел в строках `.word` и нажмите «Собрать / сброс».

Редактирование программы требует новой сборки: при следующем шаге она выполняется автоматически с обнулением регистров. Сброс восстанавливает начальную память. После HALT для повторного запуска используйте сброс. Открытие примера заменяет текст редактора; сохраните свои изменения заранее.

Если `import tkinter` не работает, нужен Python с поддержкой Tk. Приложение проверено с Python 3.12 и Tk 8.6 на macOS.

## Что происходит

Ассемблер переводит текст в машинные слова. Процессор читает эти слова из памяти и выполняет их. Обе задачи описаны обычными программами на ассемблере; в ядре нет специальных команд «найти максимум» или «сделать свёртку».

- `core.py`: ассемблер и процессор.
- `main.py`: графический интерфейс и схема процессора.
- `examples/maximum.asm`: поиск максимального значения.
- `examples/convolution.asm`: линейная свёртка.
- `ARCHITECTURE.md`: система команд и проектные решения.
- `REPORT.md`: основа отчёта и сценарий защиты.
- `tests/test_cpu.py`: автоматические проверки.
- [theory/1st_pr.md](theory/1st_pr.md): конспект по устройству процессора с пояснениями и примерами.

Проверки: `python3 -m unittest discover -s tests -v`.

## Рабочие допущения

Размер каждого входного массива — 6. Максимум возвращается без индекса. Под «сверсткой» понимается линейная свёртка с 11 результатами. Числа uint32, переполнение по модулю 2³². Эти решения пока не подтверждены методичкой. Название Neumann Lab относится к приложению; папка проекта — `cpu-emulator`.
