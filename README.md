# Эмулятор процессора — вариант 11

Практика по дисциплине «Разработка программно-аппаратного обеспечения информационных и автоматизированных систем».

| Параметр варианта 11 | Значение |
|---|---|
| Адресность | трёхадресная |
| Архитектура | фон Неймана (команды и данные в одной памяти) |
| Задание 1 | поиск максимума в массиве |
| Задание 2 | свёртка двух массивов по 6 элементов, S = Σ Aᵢ·Bᵢ, обязательно длинная арифметика |
| Числа | целые без знака |

## Запуск

Нужен только Python 3.10+ с Tkinter, сторонних библиотек нет.

```
python3 main.py                              # графический эмулятор
python3 -m unittest discover -s tests        # проверки
python3 assembler.py examples/maximum.asm    # листинг: адрес, машинный код, ассемблер
```

В окне: кнопки **Maximum** и **Convolution** загружают готовые программы, **Step** выполняет одну команду, **Run** — до `HLT`, **Reset** возвращает исходное состояние. Текст программы можно править прямо в окне; после правки **Assemble** (или просто **Step**) собирает её заново. Изменённые регистры и ячейки памяти подсвечиваются жёлтым, следующая команда — голубым.

## Машина в двух словах

- Память: 4096 ячеек по 16 бит, общая для команд и данных.
- Регистры: R0…R15 по 16 бит, счётчик команд PC, регистр команд IR, флаги Z, C, S.
- Команда: 32 бита (две ячейки), один формат для всех команд:

```
 31      24 23 22 21 20 19   16 15   12 11          0
┌──────────┬─────┬─────┬───────┬───────┬─────────────┐
│   КОП    │ ТП  │ ТИ  │  A1   │  A2   │     A3      │
└──────────┴─────┴─────┴───────┴───────┴─────────────┘
   8 бит    2 б.  2 б.  4 бита  4 бита     12 бит
```

КОП — код операции; ТП и ТИ — тип адресации приёмника и источника (00 регистровая, 01 непосредственная, 10 прямая, 11 косвенно-регистровая); A1 — регистр результата; A2 — регистр первого операнда; A3 — второй операнд: номер регистра, число или адрес.

Полное описание — в `REPORT.md` и `docs/guide.pdf`.

Файл `theory/1st_pr.md` — старый конспект к прежней (двухадресной) версии; параметры машины в нём не соответствуют текущему коду.
