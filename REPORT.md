# Основа отчёта: учебный эмулятор процессора

## Цель

Разработать на Python модель двухадресного процессора фон Неймана, ассемблер и графический интерфейс для наблюдения за выполнением двух алгоритмов.

## Принятые требования

Пользователем заданы Python, графический интерфейс, отображение этапов, парсер ассемблера, поиск максимума и операция над двумя массивами беззнаковых целых. Разрядность 32 бита, память 256 слов, 8 регистров и линейная свёртка выбраны как предварительные проектные решения. Файл теории был пуст. Перед окончательной сдачей требуется сверить эти решения с преподавателем.

## Алгоритм максимума

Первый элемент становится текущим максимумом. Последующие пять элементов сравниваются с ним; при большем значении максимум заменяется. Итог записывается в ячейку result. Время O(n), дополнительная память O(1). Для [12, 7, 99, 4, 31, 18] результат 99.

## Алгоритм свёртки

Для A и B длины 6 результат C имеет длину 11. Формула: C[k] = сумма A[i] × B[k−i] для допустимых индексов. Реализация сначала обнуляет C, затем двумя вложенными циклами выполняет C[i+j] += A[i] × B[j]. Время O(nm). Все вычисления производятся по модулю 2³².

Для A = [1, 2, 3, 4, 5, 6] и B = [6, 5, 4, 3, 2, 1] результат: [6, 17, 32, 50, 70, 91, 70, 50, 32, 17, 6]. Например C[1] = 1×5 + 2×6 = 17.

## Реализация и проверка

Ядро не зависит от интерфейса. Ассемблер формирует машинные слова, GUI отображает состояние модели после каждого этапа. Пять автоматических тестов проверяют максимум (43 массива), свёртку (40 воспроизводимых случайных пар), этапы и переполнение, ошибки сборки/адресации, изменение команды через общую память. Эталонные вычисления на Python используются только в тестах.

Отдельно проверено создание окна Tkinter и выполнение обеих демонстраций через обработчик шагов интерфейса. Это функциональная проверка; ручную оценку внешнего вида на компьютере для защиты следует выполнить отдельно.

## Сценарий демонстрации

1. Запустить приложение и выбрать максимум.
2. Объяснить R0 (указатель), R1 (максимум), R2 (счётчик).
3. Тремя нажатиями «Этап» показать выборку, декодирование и выполнение MOV.
4. Запустить программу до HALT, показать result = 99.
5. Изменить массив, собрать и повторить.
6. Выбрать свёртку, установить 1–10 мс/этап и запустить.
7. Показать 11 результатов, объяснить один элемент по формуле.
8. Показать память: машинные команды и числа находятся в одной таблице.
9. Показать понятную ошибку парсера, например `MOV R8, #1`.

## Перед окончательной сдачей

Уточнить вид свёртки и правила переполнения; добавить реальные материалы лекции; оформить титульный лист по требованиям вуза, сведения об авторе и группе, скриншоты и требуемые преподавателем блок-схемы.
